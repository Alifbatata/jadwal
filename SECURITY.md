# Sécurité

## Signaler une vulnérabilité

Utilisez le signalement privé de GitHub (« private vulnerability reporting ») :

<https://github.com/Alifbatata/jadwal/security/advisories/new>

N'ouvrez pas d'issue publique et ne publiez pas de détails avant qu'un correctif soit disponible.
Nous accusons réception dès que possible et convenons avec vous d'un calendrier de publication.

## Versions concernées

Le projet est en développement et n'est pas encore utilisable en production : aucune version n'est
supportée pour l'instant. Seule la branche `main` est suivie.

## Périmètre

- Le code de ce dépôt (`apps/web`, `packages/*`).
- La chaîne d'approvisionnement du dépôt (dépendances, CI).

L'instance hébergée par l'auteur sera couverte à partir de son ouverture (étape 8 de la feuille de
route dans `docs/CADRAGE.md`).
