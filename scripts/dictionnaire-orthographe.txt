# Dictionnaire du projet, pour `pnpm orthographe`.
#
# **Il ne contient que de vrais mots** : des noms propres, des termes du métier, et des mots d'une
# langue citée dans un texte français. Un nom de code, de fichier, de colonne ou de commande n'y
# entre pas : sa place est entre accents graves dans le document, où il se lit comme du code et où
# le correcteur ne le relit plus.
#
# Un mot n'entre ici que s'il est **juste** et que le correcteur ne le connaît pas. Un mot mal
# orthographié qu'on ajouterait ici cesserait d'être corrigé pour toujours, dans tous les textes.
#
# Un mot par ligne. La comparaison se fait telle quelle et en minuscules.
